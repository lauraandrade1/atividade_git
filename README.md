Repositório do Grupo - Anotações e Guia de Estudos

Este repositório foi criado para a *Atividade Avaliativa (Repositório em Equipe)*. O objetivo do projeto é aplicar na prática o ciclo de colaboração no Git e GitHub, incluindo a criação de repositórios remotos, colaboração entre integrantes, controle de versões e registro de histórico de commits.

##  Sobre o Projeto

O repositório funciona como uma central unificada de anotações de aula e recursos de estudo da equipe. Ele contém:
1. Resumos de conteúdos abordados em sala de aula.
2. Scripts e códigos de apoio para os exercícios práticos.
3. Lista de tarefas e cronograma de atividades do grupo.

---

##  Tecnologias e Ferramentas

* *Git*: Controle de versionamento local.
* *GitHub*: Hospedagem e trabalho colaborativo em nuvem.
* *Markdown*: Formatação de documentação e anotações.
