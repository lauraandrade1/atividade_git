# Repositório do Grupo - Anotações e Guia de Estudos - laura-andrade

Este repositório foi criado para a Atividade Avaliativa de Git e GitHub em Equipe. O objetivo do projeto é aplicar na prática os conceitos de versionamento e colaboração utilizando Git e GitHub, registrando as contribuições de todos os integrantes por meio de commits.

## Sobre o Projeto

O repositório funciona como uma central de anotações e materiais de estudo da equipe. Ele contém:

- Resumos de conteúdos abordados em aula;
- Códigos de apoio para exercícios práticos;
- Lista de tarefas e organização das atividades do grupo.

## Tecnologias e Ferramentas

- Git – Controle de versionamento;
- GitHub – Hospedagem e colaboração em equipe;
- Markdown – Formatação da documentação.

## Histórico de Contribuições

Ao final da atividade, o histórico de commits pode ser consultado com:

```bash
git log
```

ou

```bash
git log --oneline
```

para verificar a participação de todos os integrantes.
